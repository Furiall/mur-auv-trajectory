# Программа автоматического управление АНПА по заданной траектории в симуляторе MUR IDE

Программа на языке Python доя автоматического движения по заданной траектории АНПА в симуляторе MUR IDE

## Код программы

Программу можно найти в папке `src` под названием ANPA.py

## Краткое руководство пользователя

## 1. Требования к программному и аппаратному обеспечению
| Компонент | Требование |
| Операционная система | Windows 10/11 |
| Среда разработки | MUR IDE (установленная) |
| Язык программирования | Python 3.14 |
| Оперативная память | 2 ГБ и выше |
| Свободное место на диске | 100 МБ |

> **Примечание:** Для запуска программы необходимо, чтобы симулятор MUR IDE был установлен и запущен.

---

## 2. Запуск программы

### Подготовка к работе

1. Убедитесь, что симулятор MUR IDE установлен на вашем компьютере.
2. Запустите симулятор MUR IDE.
3. Создайте новый проект или откройте существующий.

### Запуск программы

1. Скопируйте код программы в редактор MUR IDE.
2. Сохраните файл с расширением `.py`
3. Нажмите кнопку "Run" в среде MUR IDE или клавишу `F5`.

## 3. Работа с программой

- **Выбрать тип траектории** введите с клавиатуры номер выбранной траектории (1,2 или 3)
- **Ввести параметры траектории** введите с клавиатуры параметры для выбранной траектории
- **Выполнение миссии** программа выполняется автоматически, в консоли будет отображаться телеметрия аппарата.

## 4. Полное руководство

Полное руководство можно найти в папке `doc`.
